# AI Dungeon Master - AI Context

> This file provides context for AI assistants working with this codebase.
> Repository: https://github.com/AusSherro/AIDungeon

## Project Overview

A Discord bot that acts as an AI Dungeon Master for D&D 5e campaigns. It uses GPT-4o for narrative generation and ElevenLabs for text-to-speech, enabling voice-narrated tabletop RPG sessions.

**Version:** 3.1.0  
**Status:** Feature-complete with full automation (v3.0 milestone achieved)  
**Commands:** 76 slash commands (consolidated from ~120)

**Key Features:**
- Full D&D 5e mechanics (combat, spells, conditions, equipment)
- Automatic combat initiation from AI narration
- Autonomous quest creation and completion
- Dynamic environment generation
- Intelligent travel with world map building
- Session continuity with auto-resume
- Voice narration with TTS
- Tactical maps and player handouts

## AI Structured Tags

The AI uses structured tags in narration that the bot parses:

| Tag | Example | Effect |
|-----|---------|--------|
| `[COMBAT:]` | `[COMBAT: 3 goblins, 1 hobgoblin]` | Starts combat |
| `[SURPRISE:]` | `[SURPRISE: enemies]` | Sets surprise round |
| `[QUEST:]` | `[QUEST: name="...", type=rescue]` | Creates quest |
| `[QUEST_COMPLETE:]` | `[QUEST_COMPLETE: "Quest Name"]` | Completes quest |
| `[RUMOR:]` | `[RUMOR: "Strange lights..."]` | Records rumor |
| `[TRAVEL:]` | `[TRAVEL: destination="...", distance=15]` | Starts travel |
| `[ARRIVAL:]` | `[ARRIVAL: "Phandalin"]` | Completes travel |
| `[LOCATION_DISCOVERED:]` | `[LOCATION_DISCOVERED: name="...", terrain=...]` | Adds location |
| `[WEATHER:]` | `[WEATHER: rain]` | Sets weather |
| `[LIGHTING:]` | `[LIGHTING: dim]` | Sets lighting |
| `[LOCATION:]` | `[LOCATION: Dark Cave]` | Sets location with preset |
| `[TIME:]` | `[TIME: 3 hours pass]` | Advances time |
| `[TRAP:]` | `[TRAP: pit trap, DC 15]` | Places trap |
| `[Voice:]` | `[Voice: Gundren]` | TTS voice selection |

## Development Notes

### Command Consolidation Pattern
Commands are consolidated using action parameters:
```python
@bot.tree.command(name="quest")
@app_commands.choices(action=[
    app_commands.Choice(name="list", value="list"),
    app_commands.Choice(name="view", value="view"),
    # ...
])
async def quest_command(interaction, action: str, name: str = None, ...):
    if action == "list":
        # Handle list
    elif action == "view":
        # Handle view
```

### Automation Systems
All automation (combat detection, quest creation, travel, etc.) uses **utility functions**, not Discord commands. This means:
- Consolidating commands doesn't break automation
- Functions like `create_quest()`, `complete_quest()` are called directly
- AI structured tags are parsed and routed to functions

### Modifying DM Behavior
Edit `utils/prompt_builder.py` - the `build_system_prompt()` function constructs the full AI context including:
- Character state
- Combat state
- Quest context
- Environment context
- Session pacing
- Structured tag instructions

## Known Limitations

- Voice output requires FFmpeg installed
- Global command sync can take up to 1 hour on Discord
- Character data is per-Discord-user, not per-campaign
- Map size limited to ~20x20 for Discord display
- ElevenLabs has rate limits (falls back to Edge TTS)
